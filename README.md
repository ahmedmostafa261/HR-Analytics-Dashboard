# HR Analytics Dashboard

An interactive HR analytics dashboard built to analyze workforce data across multiple dimensions including employee distribution, recruitment sources, satisfaction scores, performance metrics, and attrition trends.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling

## Key Insights
- Employee distribution across departments and demographics
- Attrition patterns and root cause analysis
- Recruitment source effectiveness
- Performance and satisfaction score tracking
